## We're Looking for Harness Engineers

> **TurboFlux is looking for Harness engineers to build the next generation of open-source Agent workbenches.**

We're looking for people who want to work deeply on Agent infrastructure, especially:

- Agent runtimes, task orchestration, and event streams
- Context lifecycles, long-running task recovery, and state consistency
- Streaming, tool execution, observability, and performance
- Browser / Computer Use, MCP, Plugins, and Skills
- Desktop, TUI, testing infrastructure, and cross-platform engineering

You don't need to know everything. If you have sound engineering judgment, diagnose problems with evidence, and care about building complex systems properly, introduce yourself through [TurboFlux Issues](https://github.com/aibinghezzz-stack/TurboFLux-Os/issues) and share something you've built.

## What I Care About

```text
Agent Runtime      → Stable, observable, recoverable long-running execution
Harness Design     → Clear event streams, tool boundaries, and context lifecycles
Local First        → User-controlled data, model credentials, and execution
Real Work          → Browser, computer, files, terminal, and office workflows
Open Source        → Reproducible issues, transparent architecture, quality collaboration
```
